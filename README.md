# ChatGPT Submod - Five Linux Distros Dialogues

An unofficial fan-made dialogue submod for **Monika After Story (MAS)**.

Monika gets to talk about five popular Linux distributions, their features, philosophies, package managers, and differences.

## 🐧 Supported Linux Distributions

- **Ubuntu** – A user-friendly Linux distribution based on Debian.
- **Arch Linux** – A lightweight, highly customizable rolling-release distribution.
- **Fedora** – A modern distribution focused on new technologies.
- **Linux Mint** – A comfortable and beginner-friendly desktop distribution.
- **Debian** – A community-driven distribution known for stability.

## ✨ Features

- 5 individual dialogue topics.
- English conversations.
- Separate files for each Linux distribution.
- Easy-to-edit project structure.
- Designed for Monika After Story.

## 📥 Installation

1. Download or clone this repository.
2. Extract the project folder.
3. Move `ChatGPT-Submod-Five-Linux-Distros-Dialogues` into your MAS `DDLC/game/Submods/` directory.
4. Launch Monika After Story.
5. Look for the new Linux-related conversation topics.
